12. //
-----------------------String-Constant-Pool---|

    -> So, Reference variables-> Stack.
    -> JVM-> Heap-> Object
    -> Heap-> Stack-> Stack Constant Pool.

    -> So in java, when we create string it stored in string-constant-pool where it is stored and we cannot change it.
        -> Ex-> Strign s1 = "Aditya"
                s1 = s1 + "Dadhich"
                -> Output-> Aditya Dadhich
    -> But in this s1 is reference varaible and string "Aditya" is stored in string-object-pool but when we change it cannot change or replace by Aditya Dadhich.
    -> So conclusion is-> Seperate space is created for "Aditya Dadhich" in stack constant pool.
    -> And old "Aditya" after certain time is go to garbage collection.

//-----------------------String-Constant-Pool---|
